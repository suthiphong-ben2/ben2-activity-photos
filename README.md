# ระบบภาพกิจกรรม โรงเรียนเบญจมราชรังสฤษฎิ์ ๒

ค้นหารูปกิจกรรมของตัวเองด้วยใบหน้า ดูรูปตามกิจกรรม และให้ครูโสตฯ อัปโหลดรูปได้ในที่เดียว
หน้าเว็บอยู่บน GitHub Pages รูปเก็บใน Google Drive ของบัญชี picture@ben2.ac.th ผ่าน Google Apps Script
(โครงสร้างเดียวกับระบบจองห้องประชุม ปฏิทินโรงเรียน และตารางเรียน)

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าหลัก: อัลบั้มภาพกิจกรรมแยกตามปีการศึกษา (ปีการศึกษาเริ่ม พ.ค.) · ค้นหาด้วยใบหน้าเป็นตัวเสริม · ขอไม่ให้ค้นเจอหน้า |
| `upload.html` | หน้าอัปโหลดรูปสำหรับครูโสตฯ (ชื่อ + PIN) สร้างกิจกรรมใหม่และทำดัชนีใบหน้าระหว่างอัปโหลด |
| `admin.html` | หน้าผู้ดูแล (รหัสผ่าน): ทำดัชนีรูปที่นำเข้า Drive เอง · จัดการผู้อัปโหลด · คำขอไม่ให้ค้นเจอหน้า |
| `config.js` | ลิงก์ Web app ของ Apps Script (แก้ไฟล์นี้ไฟล์เดียว) |
| `assets/` | สไตล์และโค้ดที่ใช้ร่วมกัน (เรียก API, ตรวจจับใบหน้า) |
| `apps-script/Code.gs` | โค้ดหลังบ้าน วางใน Apps Script ของบัญชี picture@ |
| `wordpress-embed.html` | โค้ดฝังหน้าในเว็บ ben2.ac.th |

- โฟลเดอร์รูป: https://drive.google.com/drive/folders/12apQS-GPzhqnn8nZadRKJ7vLvKlJcQjH (Drive ของ picture@)

## ทำงานอย่างไร

- ตัวตรวจจับใบหน้า ([face-api](https://github.com/vladmandic/face-api)) ทำงานในเบราว์เซอร์ทั้งหมด
  แปลงใบหน้าเป็นตัวเลข 128 ค่า ไม่ต้องมีเซิร์ฟเวอร์ AI
- ดัชนีใบหน้าเก็บเป็นไฟล์ JSON ในโฟลเดอร์ `_face_index` (1 ไฟล์ต่อ 1 กิจกรรม) — **ห้ามแชร์โฟลเดอร์นี้**
- 1 โฟลเดอร์ย่อยในโฟลเดอร์หลัก = 1 กิจกรรม ตั้งชื่อ `ปปปป-ดด-วว ชื่อกิจกรรม` (พ.ศ.) หน้าเว็บจะเรียงจากใหม่ไปเก่า
- เซลฟี่ที่ใช้ค้นหาไม่ออกจากเครื่องผู้ใช้ ส่งไปเพียงค่าตัวเลขใบหน้า และหลังบ้านไม่บันทึก

## ติดตั้ง (ครั้งแรกครั้งเดียว)

1. ล็อกอินบัญชี **picture@ben2.ac.th** → script.google.com → โปรเจกต์ใหม่ (หรือใช้โปรเจกต์ "BEN2 Activity Photos")
2. วางโค้ดจาก `apps-script/Code.gs` · เปิด appsscript.json แล้วเพิ่มบริการ **Drive API (v3)**
3. เลือกฟังก์ชัน **setupOnce** → เรียกใช้ → อนุญาตสิทธิ์ (สร้างโฟลเดอร์ `ภาพกิจกรรม BEN2` ให้)
4. **การทำให้ใช้งานได้ → รายการใหม่ → เว็บแอป** · เรียกใช้ในฐานะ: **ฉัน** · ผู้มีสิทธิ์เข้าถึง: **ทุกคน** → คัดลอกลิงก์ `/exec`
5. วางลิงก์ใน `config.js` แล้ว push ขึ้น GitHub · Settings → Pages → Deploy from a branch (main / root)
6. เปิด `admin.html` → **ตั้งรหัสผ่านผู้ดูแลทันที** (ตั้งได้ครั้งเดียว) → แท็บ "ผู้อัปโหลด" เพิ่มชื่อครูโสตฯ พร้อม PIN

## ใช้งาน

- **ครูโสตฯ:** เปิด `upload.html` → เลือกชื่อ + PIN → กิจกรรมใหม่ (วันที่ + ชื่อ) หรือกิจกรรมเดิม → ลากรูปมาวาง → อัปโหลด
  ระหว่างอัปโหลดระบบหาใบหน้าและทำดัชนีให้ทันที · เน็ตหลุดให้เลือกรูปชุดเดิมแล้วกดอีกครั้ง ระบบข้ามรูปที่มีแล้ว
- **รูปที่ใส่โฟลเดอร์ใน Drive เอง / รูป HEIC:** หน้าผู้ดูแล → "สร้าง/อัปเดตดัชนี" ของกิจกรรมนั้น
- **แก้ชื่อหรือลบกิจกรรม/รูป:** ทำใน Google Drive ของ picture@ ได้เลย แล้วกด "สร้าง/อัปเดตดัชนี" เพื่อเก็บกวาดดัชนี
- **แชร์อัลบั้มไปกลุ่ม LINE:** กดปุ่มเขียว "LINE" บนการ์ดอัลบั้ม หรือในอัลบั้มกด "แชร์ไป LINE" (มือถือเปิดแอป LINE ให้เลือกกลุ่ม) หรือ "คัดลอกข้อความ + ลิงก์" แล้ววางในกลุ่ม (เหมาะกับ LINE บนคอม)
  ลิงก์อัลบั้มมี `#e=...` · ลิงก์ปีการศึกษาใช้ `#y=2569` · ถ้าฝังในเว็บโรงเรียนแล้ว แก้ `BEN2PH_SHARE_URL` ใน `config.js` เป็นหน้าเว็บโรงเรียน
- **ปีการศึกษา** คิดจากวันที่ในชื่อโฟลเดอร์: เดือน พ.ค.–ธ.ค. = ปีนั้น, ม.ค.–เม.ย. = ปีก่อนหน้า · โฟลเดอร์ที่ไม่มีวันที่อยู่ในกลุ่ม "อื่นๆ" · อัลบั้มที่ยังไม่มีรูปจะไม่แสดง

## ฝังในเว็บโรงเรียน

วางโค้ดจาก `wordpress-embed.html` ในบล็อก "HTML ที่กำหนดเอง" ของหน้า WordPress (มี `allow="camera"` ให้ถ่ายเซลฟี่ในกรอบได้)

## ความเป็นส่วนตัว

ระบบนี้เปิดสาธารณะโดยไม่ต้องล็อกอิน (เหมือนระบบอื่นของโรงเรียน) จึงควร
- แจ้งผู้ปกครองและเพิ่มข้อความในหนังสือขอความยินยอมเรื่องภาพถ่าย ว่ามีระบบค้นหาด้วยใบหน้า
- อัปโหลดเฉพาะรูปกิจกรรม **ห้าม** นำรูปทะเบียน/รูปติดบัตรนักเรียนเข้าระบบ
- ผู้ที่ไม่ต้องการให้ค้นเจอ ใช้แท็บ "ไม่ให้ค้นเจอหน้าฉัน" ได้เอง ผู้ดูแลดู/ลบคำขอได้ในหน้าผู้ดูแล

## เรื่องที่ควรรู้

- แก้ `Code.gs` แล้วต้องกด **การทำให้ใช้งานได้ → จัดการ → แก้ไข → เวอร์ชันใหม่** ลิงก์ `/exec` คงเดิม
- ภาพย่อดึงผ่าน Apps Script จึงใช้โควตา UrlFetch ของ picture@ (บัญชี Workspace ได้วันละ 100,000 ครั้ง)
- ปุ่มดาวน์โหลดให้ไฟล์ด้านยาว 2048 px · ไฟล์ต้นฉบับอยู่ใน Drive ของ picture@
- ผู้ดูแลลืมรหัสผ่าน: ใน Apps Script → การตั้งค่าโปรเจกต์ → ลบ Script property `ADMIN_HASH` แล้วตั้งใหม่ที่ `admin.html`
